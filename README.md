# Float Labs

Three Fedora Atomic desktops, on Fedora's own clock.

| | |
|---|---|
| **Floatblue** | GNOME on Bluefin DX. Shipping. [repo](https://github.com/float-labs-devel/floatlabs) |
| **Kifloat** | KDE Plasma on Aurora. Planned, its own repo. |
| **CoreFloat** | Headless server on uCore. Planned, its own repo. |

Built with [BlueBuild](https://blue-build.org) on the three Fedora-based images that still
ship a real, staged release. Tracked to Fedora's release cadence, not to a nightly tree.
Hardened, but not at the cost of being able to use the machine. Written against a 3 to 4 GB
laptop with a pre-Haswell iGPU, because that is the hardware a lot of people actually have.

No money. No sponsors, no company, no paid tier. One maintainer and a hardware report from
whoever turns up. See [CONTRIBUTORS.md](CONTRIBUTORS.md).

Not affiliated with Universal Blue or the Fedora Project. We build on their images and are
grateful for them.
